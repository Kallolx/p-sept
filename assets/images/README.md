# Your assets

Every image here is a labeled placeholder. Replace each one with your own file **using the same filename**, and the site picks it up automatically. JPG or WebP both work; if you change the extension, update the path in `index.html` or `js/main.js`.

| File | Where it shows | Recommended |
|---|---|---|
| `portrait.png` | Hero, centered cut-out of you | **Transparent PNG**, ~900×1100, background removed, fades out at the bottom |
| `portrait-bw.png` | Footer, over "Let's Collab" | Same cut-out in black & white |
| `signature.svg` | Hero and Why Us card | Your signature as a white SVG (or a white-on-transparent PNG) |
| `ring-01…10.jpg` | Rotating 3D ring behind the hero portrait | Landscape ~640×440, device mockups work best |
| `work-1.jpg`, `work-4.jpg` | Featured works (landscape) | 1200×800 |
| `work-2.jpg`, `work-3.jpg` | Featured works (portrait) | 900×1080 |
| `allworks.jpg` | Thumbnail next to "All Works →" | 640×380 |
| `services.jpg` | Framed image in Services | 900×700 |
| `process-1…4.jpg` | How We Work steps | 1200×700 |
| `avatar-1…3.jpg` | Testimonial avatars | 120×120 (shown in grayscale) |
| `archive-01…12.jpg` | Idea Archive masonry (any aspect ratio) | ~900px wide |
| `about-bg.jpg` | Full-bleed About background (auto-darkened) | 1920×1100 |
| `og.jpg` | Link preview when shared | 1200×630 |

Tip: to remove a background for the portrait cut-out, try remove.bg or Photoshop's "Remove Background".
